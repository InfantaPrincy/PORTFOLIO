# Cybersecurity & Cloud Security Portfolio

A modern, professional portfolio website showcasing projects, competition participation, and practical learning in cybersecurity and cloud technologies. Built with vanilla HTML, CSS, and JavaScript for easy deployment on GitHub Pages.

**Live Portfolio:** [Your GitHub Pages URL will appear here after deployment]

## 📋 Portfolio Overview

This is not a resume or CV website—it's a project-focused portfolio designed to demonstrate practical skills and real-world experience through:

- **Projects**: Detailed case studies of cybersecurity and cloud engineering work
- **Competitions**: CTF, hackathon, and security competition participation
- **Practical Learning**: Hands-on labs, rooms, and guided learning
- **Certifications**: Relevant security and cloud certifications
- **Achievements**: Community contributions, talks, and impact

## 🚀 Quick Start

### Prerequisites
- A GitHub account
- Git installed on your computer (or use GitHub's web interface)

### Deployment Instructions

#### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and log in
2. Click the **+** icon (top right) → **New repository**
3. Name it: `<your-username>.github.io`
   - Replace `<your-username>` with your actual GitHub username
4. Add a description: "Cybersecurity & Cloud Security Portfolio"
5. Choose **Public** (required for free GitHub Pages)
6. Click **Create repository**

#### Step 2: Upload Portfolio Files
1. In your new repository, click **Add file** → **Upload files**
2. Upload these files:
   - `index.html`
   - `style.css`
   - `script.js`
3. Click **Commit changes**

#### Step 3: Enable GitHub Pages
1. Go to repository **Settings** (top menu)
2. Scroll down to **Pages** (left sidebar)
3. Under "Source," select **Deploy from a branch**
4. Select branch: **main** (or **master** if you use that)
5. Select folder: **/ (root)**
6. Click **Save**
7. Wait 2-3 minutes for deployment

#### Step 4: View Your Portfolio
Your portfolio will be live at: `https://<your-username>.github.io`

You can share this URL with recruiters!

## ✏️ Customization Guide

### Adding Your Content

All content lives in `index.html` — simply edit the HTML to add:

1. **Your Name & Headline** — Find the hero section and update text
2. **About Section** — Replace with your background and interests
3. **Projects** — Add new project cards (copy-paste existing structure)
4. **Competitions** — Add your CTF and hackathon results
5. **Learning** — Link to your TryHackMe/HackTheBox profiles
6. **Certifications** — List your certs and verification links
7. **Social Links** — Update GitHub, LinkedIn, email URLs

### Styling

- All CSS is in `style.css`
- CSS variables for colors (easy to change theme)
- Responsive design already built in
- Modify fonts, spacing, or colors as needed

### Adding Images

If you want to add images:
- Save them in the same folder as your HTML files
- Reference them in HTML: `<img src="image-name.jpg" alt="description">`
- PNG and JPG work best

## 🌐 GitHub Pages Tips

### Custom Domain (Optional)
If you want `yourname.com` instead of `github.io`:
1. Buy a domain (GoDaddy, Namecheap, etc.)
2. Go to repository **Settings** → **Pages**
3. Under "Custom domain," enter your domain
4. Save and follow DNS setup instructions

### Updates & Versions
- Edit files directly on GitHub's web editor, or
- Clone repository locally:
  ```bash
  git clone https://github.com/<your-username>/<your-username>.github.io
  git add .
  git commit -m "Update portfolio"
  git push
  ```

### Troubleshooting
- **Site not live?** Wait 2-3 minutes and hard refresh (Ctrl+Shift+R)
- **Styling looks wrong?** Check that CSS file is in the same folder as HTML
- **Links broken?** Ensure file paths match your folder structure

## 📌 Best Practices

✅ **DO:**
- Keep projects focused and well-documented
- Link to actual GitHub repositories

- Use placeholder text in final version
